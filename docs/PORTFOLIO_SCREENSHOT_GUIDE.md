# Portfolio Screenshot Guide — Baseball Stat App

## Enable Screenshot Mode

1. Open the app locally or on Streamlit Cloud
2. Sidebar → toggle **Portfolio Screenshot Mode**
3. Navigate to the hero page below

---

## Hero Page: Draft Assistant Simulator

**Why this page:** Shows next-pick rankings, team needs, scarcity scoring, and plain-language draft explanations — the strongest analytics + decision-support story.

### Desktop (1920×1080 or 1280×800)

| Step | Action |
|------|--------|
| 1 | Load FantasyPros CSVs (or use existing data) |
| 2 | Open **Draft Room Simulator** — log 3–5 picks |
| 3 | Go to **Draft Assistant Simulator** |
| 4 | Enable Screenshot Mode |
| 5 | Expand recommendations table (top 10 visible) |
| 6 | Capture full viewport showing rankings + top recommendation explanation |

**Filename:** `01-draft-assistant-recommendations.png`

### Mobile (390×844)

- Same page with Screenshot Mode on
- Scroll to top recommendation card + metrics row
- **Filename:** `02-draft-assistant-mobile.png`

### What makes it impressive

- Unified draft scoring (market rank, model rank, team needs, scarcity)
- Plain-language "why this player" explanations
- ML blend signal visible in metrics
- Connects live draft board to analytical recommendations

## Screenshot Mode Behavior

- Hides Quick guide blocks (replaced by executive summary cards)
- Collapses advanced expanders by default
- Hides debug panels and sidebar instructional captions
- Tighter vertical spacing
- Hero banner on Draft Assistant page
